Project Overview
ProdPlan is a multi-tenant SaaS platform that helps discrete manufacturers plan and track production against real 
constraints — customer orders, machine/work-center capacity, raw-material availability, and delivery deadlines. It 
replaces spreadsheet-based production planning with a single live production schedule: planners create orders, the 
system checks material and capacity availability, builds a day-by-day machine schedule, and gives floor supervisors 
and managers real-time visibility into production status against every delivery deadline.
Objectives
• Replace spreadsheet/whiteboard production planning with a single, live scheduling system.
• Automatically check machine capacity and material availability before confirming an order into the schedule.
• Give planners a visual, day-by-day machine schedule that highlights conflicts and overloads.
• Give managers real-time visibility into production status against every delivery deadline.
• Support multiple manufacturing units (tenants) on one platform, each with isolated data and configuration.
• Flag material shortages and at-risk delivery dates automatically, instead of relying on manual follow-up.
User Roles
Admin (plant/company owner — full configuration access), Production Planner (creates orders, builds and adjusts the 
schedule), Floor Supervisor (updates production status, views assigned schedule), and Viewer (read-only access to 
dashboards and reports).
Functional Requirements
• User login and signup (email/password authentication) with role-based access control.
• Multi-tenant setup so each manufacturing unit's orders, machines, materials, and schedules are fully isolated.
• Order management: create/import customer orders with product, quantity, priority, and delivery deadline.
• Machine & work-center master data: capacity per shift, working calendar, downtime/maintenance blocking.
• Material master & inventory: stock on hand, unit of measure, reorder threshold, per-product bill of materials 
(BOM).
• Production scheduling engine: sequences orders across machines based on capacity, material availability, and 
deadline priority, and flags conflicts (overloaded machine, insufficient material, missed-deadline risk).
• Visual schedule / planning board: day-by-day, machine-by-machine view (Gantt-style) with drag-to-reschedule.

• Production status tracking: stage-wise status per order (queued, in-progress, on-hold, completed) with floor-level

• Delivery deadline tracking with automatic at-risk / delayed flags visible on the dashboard.
• Admin analytics dashboard: machine utilization, on-time delivery rate, material shortages, order throughput.

• Responsive web UI for both office planning use and floor-level (tablet) status updates.
Non-Functional Requirements
• Encryption in transit and at rest.
• Per-tenant data isolation.
• Role-enforced API access.
• Full audit logging of schedule and order changes.
• Sub-2-second page loads for planning board and dashboards.
• Architecture that scales from a single pilot plant to multiple manufacturing units.
• 99.5%+ target uptime.
AI & Automation
• AI-assisted schedule optimization: given open orders, machine capacity, and material stock, suggests a conflict-
minimized production sequence rather than requiring the planner to sequence manually.
• Material shortage prediction: cross-checks BOM requirements for scheduled orders against current stock and 
reorder lead time, and proactively flags orders at risk before they hit the floor.
• Delivery-risk detection: continuously re-evaluates the schedule as status updates come in and surfaces orders likely 
to miss their deadline, with the contributing reason (capacity, material, or delay upstream).
• Scheduled notification engine for conflicts, shortages, and at-risk deadlines — email and in-app.
Payment Integration
Not required for this engagement — ProdPlan is an internal operations tool, not a payments product. If a future phase 
adds paid subscription billing for manufacturing units, the architecture should not need to be redesigned to add it.

Acceptance Criteria
All modules listed under each milestone are complete, responsive, tested, deployed to production, and delivered with

Deployment & Go-Live
The following deployment tasks are included as part of Milestone 3 and completed before final handover:
• Domain connection: pointing the client's domain/subdomain to the production environment and configuring DNS 
records (A/CNAME).
• Hosting setup: provisioning and configuring the production hosting environment (e.g., Hostinger/VPS or equivalent 
cloud host).
• SSL certificate installation for secure (HTTPS) access.
• Production database setup, connection security, and backup configuration.
• Environment variables and secrets configured for the live environment (separate from staging).
• Final smoke testing on the live domain across all core workflows.
• Go-live cutover and post-deployment verification.
